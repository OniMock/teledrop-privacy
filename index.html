TeleDrop — Privacy Policy

Last updated: 2026-08-28

TeleDrop is a Chrome extension that scans media already shown on Telegram Web and lets the user download selected items. It runs only on https://web.telegram.org/.

Data handled on the device

The extension reads information already visible or available to the Telegram Web page, only to identify and download items the user selects:

  • Telegram message identifiers already present in the page (mid, peerId, docId)
  • Media metadata such as type, filename, size, dimensions, or duration when the page exposes them
  • Media URLs or blobs already exposed by Telegram Web
  • Media already shown in the open chat, and, when the user opens them, Telegram Web Info tabs such as Photos, Files, and Stories
  • When the user enables those options, avatars / profile pictures and website link-preview media that Telegram Web already shows

This is website content processed locally in the browser. TeleDrop does not operate a developer-controlled server and does not send chat messages, media files, contacts, cookies, or account credentials to any developer-controlled server.

Requests to Telegram, not to the developer

When the user starts a download, the extension may request the file from Telegram using Telegram Web’s own download manager or a media URL already on the page. Those requests go to Telegram’s servers in the user’s existing logged-in session. They are not sent to the TeleDrop developer.

The extension may also read the browser UI language on the device to pick a translation when language is set to Automatic. That value stays on the device.

Local storage

Preferences are stored only on the user’s device with Chrome’s storage.local API. They never leave the device through this extension. This may include:

  • Interface language preference
  • Default scan filters
  • Whether automatic scan is enabled
  • Whether download buttons are shown on media
  • Whether profile photos and link-preview media are included in scans
  • Last scanner layout (large thumbnails, compact thumbnails, or details)
  • Position of the floating scanner button on the page

MAIN-world script

A content script runs in the page’s MAIN JavaScript world so the extension can call Telegram Web’s own download manager when the user requests an original-quality file. That access is used only after the user clicks Download, Download RAR, or a TeleDrop download button (chat media, Stories viewer, or media viewer). It is not used to collect, store, or send chat content, contacts, or credentials to the developer.

Downloads

Files are saved to the user’s computer by the browser or by Telegram Web. Optional RAR packaging happens locally in the browser. The scan covers only media currently present on the page (the open chat and any open Info tab). It does not fetch the full chat history by itself.

The extension uses Chrome’s downloads API only to see when a save that TeleDrop started has finished (so batch downloads stay sequential) or was interrupted. It does not read the contents of downloaded files, and it does not start, cancel, or change unrelated downloads.

Third parties

The extension does not sell user data and does not include advertising, analytics, or crash-reporting SDKs. Telegram Web remains subject to Telegram’s own privacy policy and terms. Download traffic to Telegram is described above.

If the user taps Buy me a coffee, the browser opens Buy Me a Coffee (buymeacoffee.com/onimock) in a new tab. That site has its own privacy policy. TeleDrop does not send chat or media data there.
